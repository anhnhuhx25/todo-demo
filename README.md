# To-Do List App

A simple, elegant to-do list web application with a clean interface and useful features.

## Features

- Add tasks with title and detailed notes
- Mark tasks as complete/incomplete
- Edit task notes
- Delete tasks
- Real-time clock display
- Automatic saving to local storage
- Responsive design with customized color scheme

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Local Storage API

## Usage

Simply open `index.html` in any modern web browser to use the application.
